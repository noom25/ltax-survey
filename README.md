======== วิธีใช้บนมือถือ (แบบพกไปสนาม) ========
หรือเปิดผ่าน link github
https://noom25.github.io/ltax-survey/
=============================================

⚠ สำคัญ: อย่าเปิด index.html ตรง ๆ (แบบ file://) เพราะ iPhone/iPad จะไม่เก็บข้อมูล
ต้องเปิดผ่านแอปที่ทำ web server ในตัวเครื่อง (เอกสารนี้มี 2 ทางเลือก: Documents / a-Shell)

----- ขั้นตอน (iPhone/iPad) -----
1. ติดตั้งแอป "Documents" (โดย Readdle) จาก App Store
2. โอนโฟลเดอร์นี้ (web mobile) เข้าแอป Documents
   วิธีง่าย: กดคัดลอกไฟล์ทั้ง 8 ไฟล์ จากเครื่องคอม ไปเก็บไว้ในโฟลเดอร์เดียวกันในแอป
   (หรือ Zip โฟลเดอร์นี้แล้วโอนเข้า แล้วแตกไฟล์ในแอป)
3. ในแอป Documents แตะไฟล์ index.html → เปิดด้วยในแอป (Safari ในแอป)
   แอปจะ serve เป็น http://localhost ให้อัตโนมัติ → ข้อมูลจะถูกเก็บได้
4. เริ่มกรอกข้อมูลตามปกติ (หน้าแรก -> เข้าฟอร์ม -> บันทึก -> กลับหน้าแรก)
5. เมื่อกรอกครบ กด "รวมข้อมูล (JSON)" -> ได้ไฟล์ ltax_data_all.json
6. โอนไฟล์ ltax_data_all.json กลับคอมฯ ไปวางที่ C:\LTAX_Automation\bot_upload_data v1\
7. ที่คอมฯ ดับเบิลคลิก start_server.bat แล้วบนคอมเปิด http://localhost:8000
   เข้า index.html กด "ส่งข้อมูลไปคอมฯ" แบบเลือกไฟล์... (ไม่ได้ — ดูข้อ 7.1)

   *** จริง ๆ ทำแบบนี้แทน: ที่คอมฯ รัน: python json_to_excel.py
       -> ได้ owner_land_building_template.xlsx + photos/ ครบ
       -> แล้วรัน run_all.py เพื่ออัป LTAX Online ***

----- หมายเหตุ -----
- ปุ่ม "ส่งข้อมูลไปคอมฯ" ใช้ได้เฉพาะตอนเข้าเว็บผ่าน server บนคอมฯ
  (http://192.168.x.x:8000) เท่านั้น — ในโหมดพกสนาม ให้ใช้ปุ่ม "รวมข้อมูล (JSON)" แทน
- รูปที่ถ่าย/เลือกในฟอร์มจะฝังอยู่ใน JSON เอง ไม่ต้องเก็บไฟล์รูปแยก

===== ทางเลือก 2: ใช้ a-Shell (ฟรี ไม่มี paywall) =====
ใช้แทน Documents ได้เลย ถ้า Documents บังคับให้ซื้อ/จ่ายเงิน

----- ขั้นตอน (iPhone/iPad) -----
1. โหลดแอป "a-Shell" (ฟรี, open source) จาก App Store
2. เอาโฟลเดอร์นี้เข้า a-Shell:
   แอป Files -> กดค้างที่โฟลเดอร์ -> แชร์ -> "Open in a-Shell"
3. เปิด a-Shell แล้วพิมพ์คำสั่ง (เหมือนรัน AppServ จิ๋วในเครื่อง):
   cd downloads
   python3 server.py
   (ถ้าโฟลเดอร์อยู่ที่อื่น ให้ cd ไปที่ตรงนั้นก่อน)
4. เปิด Safari พิมพ์ http://localhost:8000 -> ใช้ฟอร์มได้ ข้อมูลเก็บได้ครบ
   (เก็บไว้ 1 แท็บ แล้วสลับกลับมาใช้แทนที่ Safari จะปิด)
5. ใช้ตามขั้นตอนข้อ 4-7 ของ Documents ข้างบน (กด "รวมข้อมูล (JSON)" -> โอนไฟล์กลับคอมฯ)
6. เมื่อเลิกใช้ กด Ctrl+C ใน a-Shell เพื่อปิด server

⚠ ข้อควรรู้
- ต้องเปิด a-Shell ค้างไว้ระหว่างใช้งาน (server จะหยุดเมื่อปิดแอป)
- แนะนำตั้ง iPhone/iPad ไม่ให้ล็อกหน้าจอเอง ขณะพกไปกรอกสนาม
- ไฟล์ server.py เป็นตัว server เวอร์ชันพิเศษ: log สั้น สะอาด ไม่มี error
  BrokenPipeError ให้รำคาญตา (บน iPhone/iPad และคอมฯ ใช้ได้เหมือนกัน)
- ถ้าใช้ Android ไม่ต้องใช้แอปเหล่านี้เลย: เปิด index.html ตรง ๆ ผ่าน Chrome
  (file://) ข้อมูลเก็บได้ปกติ
