รวมข้อมูลเพื่อนำไปสร้าง Excel
รวมข้อมูล = ดาวน์โหลดไฟล์ JSON กลางไฟล์เดียว (รูปจากหน้าถ่ายรูปจะถูกแนบเข้ากับแปลง/อาคาร/ป้ายให้อัตโนมัติ)
ส่งข้อมูลไปคอมฯ = ส่งไปยังเครื่องคอมฯ ที่เปิดเว็บนี้ไว้ (แปลงเป็น Excel ให้อัตโนมัติ) — ใช้ได้เมื่อเข้าผ่าน server เท่านั้น
ลำดับการทำงาน: เพิ่มเจ้าของทรัพย์สินก่อน แล้วค่อยเพิ่ม ที่ดิน → การใช้ประโยชน์ที่ดิน / สิ่งปลูกสร้าง → การใช้ประโยชน์สิ่งปลูกสร้าง / ป้าย
ปุ่ม บันทึก ของแต่ละฟอร์มจะเก็บข้อมูลไว้ในมือถือ (localStorage) เท่านั้น — ไม่สร้างไฟล์หลุดออกมา เมื่อกรอกครบแล้วกลับมาหน้านี้ กด รวมข้อมูล เพื่อดาวน์โหลดเป็นไฟล์ JSON ไฟล์เดียว (รวมทุกหมวด) จากนั้นรัน json_to_excel.py เพื่อสร้าง Excel template ที่บอทอ่านได้

รูปภาพ: เลือกรูปในฟอร์มแล้วระบบจะฝังตัวรูป (ฐาน 64) ลงในไฟล์ JSON เอง หรือจะถ่ายเป็นชุดผ่านหน้าถ่ายรูป (เลือกหมวด+รหัสก่อนถ่าย ระบบจำรหัสล่าสุดให้ — กันจับคู่ผิด) — ใช้ได้ทุกเครื่อง ไม่ต้องหอบไฟล์รูปแยกกลับมา
โหมดแอป (PWA): ติดตั้งครั้งแรกจากหน้าเว็บจริง (ต้องมีเน็ต) → จากนั้นใช้งานออฟไลน์ได้ 100% ข้อมูลทุกอย่างเก็บในเครื่อง ไม่ส่งผ่านเน็ต ยกเว้นปุ่ม ส่งข้อมูลไปคอมฯ ที่ต้องใช้ในวงแลนกับเครื่องคอมฯ ที่เปิด server ไว้
