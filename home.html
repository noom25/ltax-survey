ดาวน์โหลดข้อมูลทั้งหมด (ZIP)
ชื่อเครื่อง/ผู้สำรวจ (ใช้ตั้งชื่อไฟล์):
ดาวน์โหลดตรง หยุด
วิธีใช้: กด "เริ่มดาวน์โหลดข้อมูลทั้งหมด" → กดปุ่มสีเขียว "บันทึก/แชร์" แล้วเลือก "บันทึกไปยังไฟล์" (iPhone/iPad) หรือบันทึกลงเครื่อง (Android) — ชุดถัดไปจะเตรียมให้เองจนครบ ทำออฟไลน์ได้ทั้งหมด
ไฟล์ ZIP แต่ละชุดมี data.json (ข้อมูลทุกหมวดครบทุกชุด) + manifest.json + โฟลเดอร์ photos/ (รูปจริง) · ปกติจะดาวน์โหลดเฉพาะรูปใหม่ที่ยังไม่เคยดาวน์โหลด
ควรดาวน์โหลดทุกวันหลังเลิกงาน (ข้อมูลอยู่ในเครื่องนี้เครื่องเดียว) · ย้ายไฟล์เข้าคอมฯ ด้วยวิธีที่สะดวก (สายเคเบิล / Google Drive / LINE) แล้วรัน python import_export.py *.zip · ลบรูปออกจากเครื่องเมื่อนำเข้าที่คอมฯ และตรวจแล้วเท่านั้น
ข้อมูลในเครื่อง
วิธีเดิม: รวมเป็นไฟล์ JSON ไฟล์เดียว (เหมาะกับรูปไม่เกินไม่กี่ร้อยรูป)
ฝังรูปเป็น base64 ลงในไฟล์ JSON ไฟล์เดียว — รูปเยอะแล้วเครื่องอาจค้าง ให้ใช้ "ดาวน์โหลดข้อมูลทั้งหมด (ZIP)" ด้านบนแทน
ลำดับการทำงาน: เพิ่มเจ้าของทรัพย์สินก่อน แล้วค่อยเพิ่ม ที่ดิน → การใช้ประโยชน์ที่ดิน / สิ่งปลูกสร้าง → การใช้ประโยชน์สิ่งปลูกสร้าง / ป้าย
ปุ่ม บันทึก ของแต่ละฟอร์มจะเก็บข้อมูลไว้ในเครื่อง (IndexedDB) เท่านั้น — ไม่สร้างไฟล์หลุดออกมา เมื่อสำรวจเสร็จกด ดาวน์โหลดข้อมูลทั้งหมด (ZIP) แล้วนำไฟล์ไปรัน import_export.py บนคอมฯ ได้ ltax_data_all.json + โฟลเดอร์ photos/ (และ Excel ไว้ดู) สำหรับให้บอทนำขึ้น LTAX Online

รูปภาพ: ถ่ายเป็นชุดผ่านหน้าถ่ายรูป (เลือกหมวด+รหัสก่อนถ่าย ระบบจำรหัสล่าสุดให้ — กันจับคู่ผิด) หรือเลือกจากคลังรูปในเครื่อง รูปทุกใบเก็บเป็นไฟล์แยกในเครื่อง ไม่ฝังลงข้อมูลฟอร์ม
โหมดแอป (PWA): ติดตั้งครั้งแรกจากหน้าเว็บ (ต้องมีเน็ต ครั้งเดียว) → จากนั้นใช้งานออฟไลน์ได้ 100% ข้อมูลทุกอย่างเก็บในเครื่อง ไม่ส่งผ่านเน็ต · การอัปเดตแอปต้องมีเน็ตเป็นครั้งคราว ควรทำก่อนออกสำรวจ
